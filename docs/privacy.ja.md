# プライバシー

English: [privacy.md](privacy.md)

Folirel は端末の中で動くフィードリーダーです。アカウントもサーバーもなく、利用者についてのデータを集めることも、誰かに渡すこともありません。

## ネットワークに送るもの

Folirel が通信するのは、利用者が登録したサイトだけです。内容を取りに行くためにだけ通信します。

- フィード（手動の更新と、自動更新のとき）
- 記事の画像とサイトのアイコン（画像の表示をオフにしていないとき）
- サイトのページ（アイコンを探すとき。サイトを追加したときや、Folirel にリンクを共有したときは、フィードを探すためにも）

どの通信も、端末からそのサイトへ直接行います。ふつうに Web サイトを見るときと同じく、サイトには端末の IP アドレスと通信の時刻が伝わります。Folirel は User-Agent として `Folirel/<バージョン> (Android; local RSS reader)` を送ります。Cookie や、利用者・端末を識別する情報は送りません。

記事はブラウザーで開きます。そこから先は、ブラウザーとサイトそれぞれのプライバシーポリシーに従います。

## しないこと

- 利用状況の分析、広告、クラッシュレポートはありません。外部のサービスには接続しません。
- 開発者には何も送りません。
- Android のクラウドへの自動バックアップと、端末間のデータ移行は、Folirel では止めています。フィードのアドレスに個人用のトークンが含まれることがあるためです。

## データの保存場所

購読、記事、既読・保存の状態、設定は、端末のアプリ用の保存領域にだけ保存します。

Folirelのバックアップと、書き出した OPML ファイルは、利用者が選んだ場所にだけ保存します。Folirel がアップロードすることはありません。クラウドのフォルダーに保存した場合は、そのサービスにも写しが残ります。

## データの消し方

- すべて消す: Folirel をアンインストールするか、Android の 設定 > アプリ > Folirel > ストレージ で **ストレージを消去** をタップします。
- サムネイルとアイコンだけ消す: Folirel の 設定 > 保存とデータ > **画像キャッシュを削除**。
- 保存したバックアップと OPML ファイルは、保存した場所に残ります。そこで削除してください。

## 問い合わせ

プライバシーについての質問は https://github.com/yuu-biz/folirel/issues で issue を作ってください。フィードのアドレスや OPML ファイルは貼らないでください。個人用のトークンが含まれることがあります。
